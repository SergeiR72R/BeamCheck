# План работ BeamCheck

| № | Этап | Статус |
|---|---|---|
| 0 | Разведка данных PERI CAD | ✅ DWG из PERI CAD 24 разобран (см. `PERICAD24.md`); `PERIDUMP` нужен для COM-свойств (вес/артикул) и для PERI CAD 25/26 |
| 1 | Каркас: Core + общий CAD-код, сборки AutoCAD (net48) и BricsCAD (net48 / net8), bundle, установщик | ✅ |
| 2 | Расчётное ядро: колонны, ярусы, путь нагрузки дек → леджер → стойка, классы EN 12811-1, γ | ✅ покрыто тестами |
| 3 | Распознавание объектов PERI | ✅ по форме осевых линий + артикул из блоков `PERI_<арт>_…`; проверено на реальной геометрии |
| 4 | Диалог: класс, ярусы, γ, подсветка, исключить/добавить, CSV | ✅ |
| 5 | Вывод в чертёж: схема, стрелки, цепочка размеров, таблица, группа | ✅ требует проверки внешнего вида в PERI CAD |
| 6 | Испытания на реальных чертежах (PERI CAD 24 и 25/26), подбор допусков | ⏳ |
| 7 | (опц.) Проверка балки: реакции, M, прогиб, сравнение с несущей способностью | ⏳ |

## Что нужно от пользователя
1. Вывод `PERIDUMP` по балке, секции стойки, леджеру и деку в PERI CAD 24 и, по возможности, в 25/26.
2. Ручной расчёт для какой-нибудь балки, чтобы сверить с модулем числа (не только геометрию).
3. Подтвердить правило по ярусам (по умолчанию: расчётный 100 % + один соседний 50 %, остальные 0 % (так в таблицах PERI UP)).
4. Что показывать на схеме: Fk или Fd.

## Известные ограничения текущей версии
- Не проверено вживую в PERI CAD: нет доступа к среде. Сборка под AutoCAD компилируется,
  BricsCAD-вариант собирается только на машине с установленным BricsCAD.
- Для объектов, которые не являются блоками (например, 3D-тела), ось берётся по габаритам
  в мировых осях. У повёрнутых в плане тел она может определиться неверно.
- Объекты внутри сборочных блоков находятся при поиске, но подсвечивается весь сборочный блок.
- Опирание деков через консоли и кронштейны (без леджера между двумя стойками) пока не
  разбирается: такие деки попадут в предупреждения или их нужно добавить вручную.

## Сверка с таблицами PERI (Tabellenbuch PERI UP, 05/2021, стр. 42)
Тесты `PeriTableTests` воспроизводят значения «zusätzliche Stiellast infolge Verkehrslast q1»
для внутренней стойки: V = 1,5·q1·b·L/2 (3,38 / 5,06 / 2,81 / 4,22 / 4,50 / 6,75 / 8,44 / 9,00 / 11,25 кН).
Правило ярусов — по EN 12811-1: один ярус 100 % и **один** соседний 50 %.
Весов деталей по артикулам в Tabellenbuch нет (только несущая способность, кг/м профилей
и нагрузка на стойку от собственного веса на ярус) — веса берутся из `BeamCheck.weights.csv`.
